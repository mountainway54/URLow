# URLow 開發文件

URLow 原本是一個縮網址介面練習，後來補上 Server API、PostgreSQL、KV cache 和 Cloudflare Workers 部署。這裡留下開發過程中的選擇、踩過的坑，以及我使用 AI 的方式。

我先前主要寫 JavaScript，這次才開始把 TypeScript 用進完整專案。做法很直接：表單狀態盡量靠型別推論，API、資料庫和外部資料則明確定義型別。遇到看不懂的錯誤就先弄清楚原因，不用 `any` 蓋掉。
