# 實作縮網址網站｜系列引言與目錄

## 系列引言

這個系列記錄我從零規劃與實作縮網址網站的過程。題目不限制使用的程式語言、框架或套件，主要要求是參考頁面截圖完成核心功能，適當使用 Git 進行版本控制、撰寫 README，並在使用 AI 工具時保留討論過程的 Prompt。若時間允許，也會嘗試將成品部署到雲端，並錄製完整的實作過程。

縮網址服務看似簡單：使用者輸入一串網址，系統回傳較短的連結；其他人開啟短網址後，再被導向原始網站。然而，實際開發時仍需要處理短碼產生與碰撞、網址驗證、資料庫查詢、HTTP Redirect、安全性及錯誤處理等問題。

我先前主要學習 JavaScript，這次會以 Nuxt 4、Vue 和輕量 TypeScript 開發。所謂輕量 TypeScript，是沿用熟悉的 JavaScript 寫法，只在函式參數、API 回應和資料模型等重要位置加入必要型別，暫時不使用複雜泛型或高階型別。希望透過規模明確的實際專案邊做邊學，逐步理解型別系統帶來的幫助。

本系列除了記錄程式實作，也會說明需求拆解、架構選擇及技術取捨。目標是完成一個結構清楚、容易測試且能夠部署的縮網址服務，不規劃額外擴充功能。

完成前端階段後回頭整理，這次實作了響應式產品介面，以及「長網址縮址」與「短網址修改」兩種本機假資料流程；Server API、資料庫與 Redirect 則沒有納入這一階段。
